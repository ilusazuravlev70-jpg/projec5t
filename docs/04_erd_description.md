# Описание ER-диаграммы (Модуль 1)

1.  **Роли — Пользователи (1:N):** Одна роль (например, "Клиент") может быть назначена многим пользователям. Каждый пользователь имеет строго одну роль.
2.  **Пользователи — Заказы (1:N):** Один пользователь может сделать много заказов. Каждый заказ принадлежит одному пользователю.
3.  **Товары — Товарные позиции (1:N):** Одна модель обуви может иметь много товарных позиций (разных размеров). Каждая позиция относится к одной модели.
4.  **Размеры — Товарные позиции (1:N):** Один размер (например, 41) может быть у многих моделей обуви. Каждая позиция имеет один размер.
5.  **Заказы — Состав заказа (1:N):** В одном заказе может быть много товаров. Каждая строка состава принадлежит одному заказу.
6.  **Товарные позиции — Состав заказа (1:N):** Одна товарная позиция (кроссовки 42 размера) может встречаться в разных заказах. Каждая строка состава ссылается на одну конкретную товарную позицию со склада.
